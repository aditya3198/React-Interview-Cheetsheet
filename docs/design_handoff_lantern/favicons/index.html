The name

Lantern — the warm-dark UI, lit by a single amber accent, was already a lantern in everything but name. It's the light you keep on while you study at night.

The shipped file is favicons/favicon.svg. The previews above force each scheme so you can compare side-by-side. The flame dot, italic "l", and warm cream/ink are the same three tokens used everywhere else in the product.
