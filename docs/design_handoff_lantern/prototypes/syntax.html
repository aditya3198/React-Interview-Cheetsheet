Optional chaining ?.

ES2020

Short-circuit property access on null or undefined without throwing.

const u = { name: 'Ada' };
u?.address?.city ?? 'unknown';
// ▸ 'unknown'   (short-circuits at address)
[]?.[0];        // ▸ undefined
null?.fn?.();    // ▸ undefined (no throw)

Nullish coalescing ??

ES2020

Like || but only falls through on null/undefined, not on 0 or ''.

const a = 0  ?? 50;  // ▸ 0   (kept — only null/undef fall through)
const b = null ?? 50;  // ▸ 50
const c = 0  || 50;  // ▸ 50  (||  treats 0 as falsy)

Logical assignment

ES2021

Combines a logical operator and assignment into a single token.

const opts = { retry: 0 };
opts.retry ||= 3;     // ▸ opts.retry === 3  (|| sees 0 as falsy)
opts.retry ??= 9;     // ▸ opts.retry === 3  (no change — not null)
opts.dirty &&= false; // ▸ opts.dirty unchanged (was undefined)
