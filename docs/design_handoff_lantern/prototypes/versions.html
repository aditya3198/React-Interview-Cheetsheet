01

Optional chaining ?.

Lets you reach into nested objects without writing a chain of x && x.y && x.y.z guards. Short-circuits to undefined on null/undefined instead of throwing.

ES2020
syntaxhigh-impact
ES2018 — before
const city = user
  && user.address
  && user.address.city;
// ▸ undefined OR "Berlin" (verbose; loses 0/'' fallbacks)

Defensive guards everywhere. Also wrong when an intermediate value is 0 or '' — the chain collapses too eagerly.

ES2020 — after
const city = user?.address?.city ?? 'unknown';
// ▸ "Berlin"   or   "unknown" — never throws

Same intent, one line. Pairs with ?? (nullish coalescing) so legitimate 0/'' values are preserved.

02

Top-level await in modules

Modules can now suspend at the top level, removing the IIFE wrapper that every async-initialised module used to need.

ES2022
syntaxmodules
ES2018 — before
// init.js — wrapped in an async IIFE
(async () => {
  const cfg = await fetch('/cfg');
  window.cfg = await cfg.json();
})();
// ▸ consumers had to await an exported promise

Every module needing setup grew a wrapper, then exported a promise consumers had to await.

ES2022 — after
// init.js — top-level await
export const cfg =
  await (await fetch('/cfg')).json();

// ▸ importers naturally wait for cfg to resolve

Importers naturally pause until the module finishes resolving — module graph schedules around it.

03

Array .at(-1)

Finally a built-in for "last item" that works on negative indices, mirroring Python's slice semantics.

ES2022
stdlib
ES2018 — before
arr[arr.length - 1];
// ▸ last item — but you had to compute the index
//   yourself; doesn't work on iterables.
ES2022 — after
arr.at(-1);     // ▸ last item
arr.at(0);      // ▸ first item
arr.at(-2);     // ▸ second-to-last

04

Logical assignment operators

Three new operators (??=, ||=, &&=) collapse the "check-then-assign" idiom into one token.

ES2021
syntax
ES2018 — before
if (cache.user == null) {
  cache.user = await fetchUser();
}
// ▸ branch + assignment, two statements
ES2021 — after
cache.user ??= await fetchUser();
// ▸ only assigns if cache.user is null/undefined

05

with statements (in strict mode)

Modules are strict-mode by default — and with blocks throw a syntax error. Effectively retired in any modern build.

deprecated
runtime
ES2018 — gone
with (Math) {
  return pow(sin(x), 2) + pow(cos(x), 2);
}
// ▸ SyntaxError under strict mode (all modules)

Use destructuring instead — const { sin, cos, pow } = Math.

06

Promise .allSettled & .any

.all fails on the first reject. The new combinators give you "tell me every outcome" and "succeed on the first success".

ES2020 / ES2021
stdlib
ES2018 — before
Promise.all([a, b, c]).then(...)
  .catch(e => /* one fails → all lost */);
// ▸ no built-in for "give me every result"
ES2020+ — after
Promise.allSettled([a, b, c]).then(rs =>
  rs.filter(r => r.status === 'fulfilled')
);
// ▸ [ {status:'fulfilled', value}, {status:'rejected', reason} … ]

Promise.any([fast, slow, slower]);
// ▸ first resolved wins; AggregateError if all reject
